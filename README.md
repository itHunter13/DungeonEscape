# Dungeon Escape

Консольная игра на C++, в которой игрок должен выбраться из подземелья.

## Цель игры

Игрок управляет героем `@`, исследует подземелье, собирает предметы,
сражается с врагами, находит ключ и добирается до выхода.

Для победы необходимо:

1. Найти ключ `K`.
2. При необходимости победить врагов `E`.
3. Дойти до выхода `X`.
4. Иметь ключ для открытия выхода.

## Управление

| Клавиша | Действие |
|---|---|
| W | Движение вверх |
| S | Движение вниз |
| A | Движение влево |
| D | Движение вправо |
| H | Использовать зелье |
| I | Информация о персонаже |
| G | Сохранить игру |
| L | Загрузить игру |
| Q | Выйти |

## Обозначения на карте

```text
@  Игрок
E  Враг
P  Зелье
$  Монета
K  Ключ
X  Выход
#  Стена
.  Пустая клетка
```
